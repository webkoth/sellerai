## Порядок загрузки

1. **Слайдшоу.** Конструктор → секция «Слайдшоу» → формат **2:1** для десктопа и **4:3** для мобильного.
   Для каждого слайда грузятся две картинки: `_desktop` и `_mobile` из одной строки таблицы.
   Кнопки уже нарисованы на баннере — в настройках слайда кнопку можно не включать, но ссылку на слайд задать нужно:
   слайд 1 → категория «Коллекционные образцы», слайд 2 → «Украшения», слайд 3 → «Амулеты и обереги».
2. **Промо-полоса.** Секция «Слайдшоу» или «Изображение» с форматом **5:1**, один файл, без текста поверх.
3. **Окно подписки.** Настройки → баннеры и окна → «Окно подписки» → вариант «Изображение 16:9».
4. **Обложки категорий.** Каталог → категория → обложка. Файлы `06–09` уже загружены в магазин через API,
   вручную грузить их нужно, только если понадобится заменить.

## Цветовые темы

Стиль допускает два акцента (`remotionvideo/src/overlays/theme.ts`):

- **cyan** `#22D3EE` — космос, коллекционные образцы;
- **ember** `#FB4A29` — «огонь входа в атмосферу», украшения и обереги.

В наборе чередуются: слайд 1 и метеоритные категории — cyan, слайд 2 и обереги — ember, слайд 3 — cyan.
Чтобы пересобрать баннер в другой теме, поменяйте `theme` в `remotionvideo/src/kit/banners.ts` и отрендерите заново.

## Тексты на баннерах

Заголовки написаны по правилу серии: ключевое слово в `*звёздочках*` получает акцентную подсветку.
Формулировки без обещаний лечебного или магического эффекта — те же ограничения, что в описаниях товаров и статьях блога.
