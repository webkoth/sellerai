## Какой набор выбрать

| | `../kit-banners/` (космос) | `kit-banners-fashion/` (этот) |
|---|---|---|
| Фон | тёмный, `#0F1014` | слоновая кость, `#F3F0EA` |
| Шрифт | Inter КАПС, жирный | Playfair Display, сериф |
| Акцент | cyan / ember, свечение | золото `#A98C4F`, hairline |
| Фото | вырезки без фона | реальные макро из карточек |
| Ощущение | космос, техно, контраст | ювелирный дом, каталог, воздух |

Оба набора нарезаны под одни и те же слоты, поэтому их можно сравнить прямо в конструкторе
и оставить один. Смешивать не стоит: тёмный и светлый баннеры в одном слайдшоу конфликтуют.

## Пересборка

Тексты, фото и кадрирование — в `remotionvideo/src/kit/fashionBanners.ts` (`focus: "52% 48%"` двигает кадр
внутри рамки). Рендер: `npx remotion still Kit-f-<id> <файл>`, затем конвертация в JPEG:
`sips -s format jpeg -s formatOptions 90 <png> --out <jpg>`.

Чтобы взять другие образцы, скачайте вторые кадры галереи нужных товаров в `remotionvideo/public/kit-photos/`
и укажите путь в `fashionBanners.ts`. **Первые кадры галереи не подходят** — на них уже нанесены заголовки
для карточек Wildberries.
