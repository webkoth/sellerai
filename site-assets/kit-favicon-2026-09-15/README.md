# Иконка сайта из логотипа — 15.09.2026

Знак «пять падающих метеоритов» из `remotionvideo/public/brand/logo.png`, отделённый
от слова KOTELNIKOVARTIFACT.

## Два варианта

| Вариант | Файлы | Когда |
|---|---|---|
| **На тёмном** | `favicon-dark-*.png` | по умолчанию: знак светлый на почти чёрном квадрате, читается на светлой вкладке браузера |
| **Без фона** | `favicon-ink-*.png` | если KIT сам подкладывает фон: знак цвета бренда `#3D4A5E` на прозрачном |

## Размеры

`512` и `192` — для PWA и превью, `180` — apple-touch-icon, `64`, `48`, `32`, `16` — вкладка браузера.

Знак упрощается по мере уменьшения: на 512–64 все пять метеоритов, на 48 — четыре,
на 32 — три, на 16 — два. Пять тонких штрихов в 16 пикселей превращаются в серое пятно,
поэтому для мелких размеров они перерисованы крупнее, а не сжаты.

## Куда ставить

Кабинет KIT → Настройки → О компании (или Редактор сайта → Тема → Настройки внешнего вида) →
поле иконки сайта. Загружать `favicon-dark-512.png`: KIT сам сделает мелкие размеры,
но если попросит несколько — файлы лежат рядом.

Пересборка: скрипт рисует знак векторно, см. историю коммита за 15.09.2026.
