## Как готовились вырезки

1. Исходники (JPG/HEIC из съёмки) сложены в `remotionvideo/public/kit-src/` — 21 файл, 3024×4032 и 4032×3024.
2. Фон срезан локально моделью **rembg u2net** (venv `/tmp/rembg-venv`, скрипт `/tmp/cutout.py`):
   уменьшение до 2400 px по длинной стороне → `remove(post_process_mask=True)` → обрезка по границам объекта.
3. Постобработка (тот же скрипт-«полировка»): у браслетов вычищен белый фон **внутри кольца**
   (связные светлые области > 1 % кадра), у всех вырезок подрезана полупрозрачная кайма
   и погашен белый ореол по краю — иначе на тёмной подложке он читается как светлая обводка.
4. Готовые PNG с альфой — в `remotionvideo/public/kit-cutouts/` (21 шт., 250–1000 КБ).

Ни один платный сервис не использовался: Higgsfield недоступен (0 кредитов, план free).

## Пересборка вырезок

```bash
/tmp/rembg-venv/bin/python /tmp/cutout.py     # новые файлы из kit-src/ → kit-cutouts/
```
Скрипт пропускает уже готовые PNG, так что можно докладывать исходники по мере съёмки.
