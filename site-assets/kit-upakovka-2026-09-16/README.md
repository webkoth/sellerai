## Как сделано

- **Сцены** сняты в Higgsfield (Nano Banana, 2K, 3:4) по фото настоящей упаковки
  из `~/Downloads/images_origin`: мешочек `13.00.03`, чёрная коробка `13.00.59`,
  белая `13.00.37`, пара коробок `13.00.21`. Задания HS — в `manifest.json`.
- **Логотип проверен на каждом кадре** на полном разрешении: пять косых штрихов,
  KOTELNIKOVARTIFACT, линия, «Welcome to space community». Из 7 снятых кадров
  отброшены 4: полосы сверху и снизу, выдуманный значок-комета, бирюзовый бок
  коробки, которого у настоящей нет.
- **Тёплый отлив убран** на тёмных сценах (`pack-1`, `pack-2`): ключевой свет красил
  серебряное тиснение в золото, а настоящее тиснение серебряное.
- **Типографика** — шаблон карточек `KitArtifactBanner`, слоты `PACK_SLOTS`
  в `remotionvideo/src/kit/packSlots.ts`. Линия заголовка 0.76 вместо 0.68:
  это фото галереи, в сетке каталога оно не стоит.

Кредитов HS израсходовано: 21 из 26,5, по 3 за кадр. Предварительная оценка
давала 2 за кадр — с референсами дороже. Остаток 5,5.

## Где стоят старые фото

По API KIT на 16.09.2026: **255 вариантов из 394**, из них 63 опубликованы.
Скрытые меняются тоже, иначе при публикации всплывёт старая упаковка.

Фото сертификата (`01a05c99-b827…`, `01a05c99-b774…`) не трогались, хотя на их фоне
тоже видна старая упаковка.

## Замена

```
python3 scripts/kit_replace_pack_photos.py           # сухой прогон
python3 scripts/kit_replace_pack_photos.py --apply   # загрузка и замена
```

Новый кадр встаёт на место старого, остальные фото и их порядок не меняются.
В конце скрипт перечитывает все варианты и проверяет, что старых id не осталось.

Откат: `_backup-media-2026-09-16.json` — `media` всех 394 вариантов до замены.

**Перед `--apply` — утверждение владельца магазина.**

## Что проверить перед утверждением

1. «Входит в заказ без доплаты» (`pack-1`) — упаковка действительно бесплатна
   в каждом заказе? На сайте написано «без дополнительных сборов».
2. «Бархатный мешочек» (`pack-3`) — материал называется так?
3. Крупные коллекционные образцы тоже едут в этой коробочке? Фото стоят и в их карточках.
4. На кадрах одновременно чёрная и белая коробочки. Если покупатель получает одну,
   не ждёт ли он обе.
