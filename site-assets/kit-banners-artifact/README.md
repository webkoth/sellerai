## Форматы — по документации KIT

Слайдшоу в конструкторе предлагает шесть десктопных пропорций и четыре мобильных.
Каждый из четырёх сюжетов отрисован во всех одиннадцати:

| Формат | Размер | Раскладка |
|---|---|---|
| десктоп 2:1 | 2400×1200 | текст слева, изделие справа |
| десктоп 5:2 | 2400×960 | то же |
| десктоп 7:2 | 2450×700 | то же |
| десктоп 5:1 | 2400×480 | сжатая: заголовок, подзаголовок, мета |
| десктоп 10:1 | 2400×240 | строка: заголовок + мета |
| десктоп полноэкранный | 1920×1080 | текст слева, изделие справа |
| мобильный 4:3 | 1080×810 | текст слева, изделие справа |
| мобильный 7:3 | 1080×463 | сжатая |
| мобильный 5:2 | 1080×432 | сжатая |
| мобильный 7:1 | 1080×154 | строка |
| мобильный портрет 3:4 | 1080×1440 | вертикальная карточка |

Раскладка выбирается автоматически по пропорции кадра (`layoutFor` в `artifactBanners.ts`):
чем ниже полоса, тем меньше в ней остаётся — в 10:1 и 7:1 живут только заголовок и мета,
иначе текст превращается в нечитаемую мелочь.

## Тексты: что изменилось и почему

Схема осталась из макета — **серия → заголовок → уточнение → мета → факт**, но заголовки переписаны.

| Было | Стало | Что чинит |
|---|---|---|
| Материя старше Земли | **Возраст, который не подделать** | описание → заявление о подлинности; снимает главный страх покупателя дорогого метеорита |
| Космос в оправе | **Срез, который не повторится** | красивый образ → дефицит; повод не откладывать |
| Знак, который носят | **Знак, а не украшение** | нейтрально → противопоставление; отстраивает от бижутерии |
| Отправляем из Краснодара | **Бережная отправка по России** | факт логистики → снятие возражения о хрупкости |
| Первыми о новых образцах | **Узнавайте о находках первыми** | «мы вам напишем» → выгода подписчика |

Правила, по которым писались строки:

1. **Заголовок продаёт не предмет, а его роль у владельца.** Для чека 20 000 ₽ работает статус
   и подлинность, а не перечисление свойств.
2. **Каждому обещанию — доказательство рядом.** Заголовок → уточнение (что это физически) →
   мета (материал или падение) → факт (возраст, единственность). Читатель не остаётся с одними эпитетами.
3. **Дефицит только честный.** «Единственный экземпляр» и «срез не повторится» — правда для этого товара,
   а искусственных таймеров и «осталось 2 штуки» здесь нет: аудитория коллекционеров такое считывает мгновенно.
4. **Никакой эзотерической гарантии.** Ни «притягивает», ни «защищает» — только символика и материал,
   как и в описаниях товаров.
5. **Даты и падения — только проверенные.** «Метеорит Aletai · Китай · 1898» взято из вашего макета;
   где падение неизвестно, стоит тип: «Палласит · оливин в железе», «Железный метеорит · видманштеттен».

## Пересборка

Данные — `remotionvideo/src/kit/artifactBanners.ts` (сюжеты `HERO`, форматы `FORMATS`, категории).
Добавить формат — одна строка в `FORMATS`, он сам применится ко всем сюжетам.
Рендер всех: `bash /tmp/render_artifact_all.sh` либо `npx remotion still Kit-a-<id> <файл>`.
