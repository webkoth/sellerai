## Что с этим делать

- `01` и `02` — в слайдшоу, соцсети, письма. Это первые кадры «на человеке» в каталоге: у браслетов и подвесок они снимают вопрос масштаба, который по фото на белом фоне не решается.
- `03` — готовый фон-сцена для баннера: свет и cyan-rim совпадают с фирменной палитрой.
- `04` — в слайд конструктора KIT вместо статичной картинки.
- `05` — вертикаль под рилс и сторис.

**Ограничение:** это постановочные кадры вокруг реального изделия. В главное фото карточки они не идут — там только съёмка, иначе расхождение с товаром даёт основание для возврата. Для баннеров, соцсетей и писем ограничений нет.
