## Диагностика текущей витрины (20 карточек)

- Товар занимает ~15–20% кадра — на превью в выдаче подвеска почти не видна.
- 3 разных цвета заголовков (синий, бордовый, коричневый), разные компоновки, часть фото с рукой/перчаткой.
- Мелкий нечитаемый текст «Находка: …» внизу, подчёркнутый логотип выглядит устаревшим.

## Единая система (для любого выбранного стиля)

- Товар 60–70% высоты кадра, мягкая тень, фон чистый белый #FFFFFF.
- Бренд KOTELNIKOVARTIFACT — всегда сверху по центру (кроме Swiss — слева), разрядка капсом.
- Блок данных всегда внизу: тип изделия → имя метеорита (крупно) → страна · год · вес.
- Палитра: чёрный/угольный на белом + максимум один акцент (золото у №2, бейдж у №3).
