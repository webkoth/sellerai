# Фид автозагрузки Авито

Карточка: `business-os/cards/podklyuchenie-avito.md`. Реестр ключей: `business-os/tools/avito.md`.
Формат полей: `docs/api-reference/openapi/avito/` (начинать с `README.md`).

```bash
set -a; source .env; set +a
python3 avito/wb_collect.py                                  # WB → data/cache/avito/wb_*.json (кэш по шагам)
python3 avito/build_feed.py --base-url https://<хост>/<путь>  # → avito/out/feed.xml, img/, report.json
```

Кэш не обновляется сам: чтобы взять свежие остатки или цены, удалить нужный `data/cache/avito/wb_<шаг>.json`.
Цены WB у базового токена — 1 запрос на окно, его же занимают серверы синка: сборщик ждёт по 65 с на 429.

## Правила отбора (29.09.2026)

- Остаток > 0 на своём складе «Мой склад Краснодар» (1408913): с Авито отгружаем из Краснодара, не со складов WB.
- Без серебра 925 — на Авито нужен спецучёт Пробирной палаты. Цвет «серебристый» серебром не считается.
- Часы пропускаются: обязательное поле Brand берётся из справочника `brendy_fashion`, он не скачан.
- Цена — правило KIT (решение 25.09, п. 10 и 20): цена продавца WB × (1 − медиана СПП за 30 дней),
  не ниже нетто WB + 500 ₽, не выше цены продавца, вверх до 100 ₽. Мультиразмер — по меньшей цене из размеров в наличии.
- Категории: образцы, фигурки и всё «Природные материалы» → «Коллекционирование / Другое»; остальное →
  «Часы и украшения / Бижутерия», подвид по названию (в WB-предмете «Обереги» лежат и браслеты, и серьги).
- Фото WB — только webp, Авито берёт JPEG/PNG: перегоняются в `img/`, до 10 на объявление.
- Id объявления — `wb-<nmID>`, менять нельзя: по нему Авито узнаёт объявление между выгрузками.
